# Changelog

## Unreleased

- Process files locally with 140 tools for images, PDF and Office documents, video, audio, archives, tabular data and 3D models.
- Open a photo in the full-window editor to adjust light and color, add text and shapes, draw, highlight or redact. Reopen saved edits from Recent files on the homepage.
- Add several videos to one timeline, split, trim and rearrange their clips, mix in a soundtrack, and export as MP4 or WebM.
- Drag clips into order and choose a speed directly in Video Editor. Both editors now support rotation in 0.1° steps.
- Open mesh and CAD models or GLB and glTF scenes in the 3D Viewer. Select any companion buffers and textures with the scene file, explore it from different angles, and check dimensions and geometry counts.
- Drop a file to see compatible tools. Pass an output directly to another tool or download batch results as a ZIP.
- Search the catalog by format or task with Ctrl+K or ⌘K. Switch between English, Spanish, Italian, German, Portuguese and French.
- Preview changes before exporting in supported image, video and PDF tools. Use keyboard controls for crop adjustments and page placement.
- Run OCR, transcription, translation and background removal on the device after downloading the required models.
