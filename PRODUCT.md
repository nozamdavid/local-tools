# Loconvert

## Platform

web

## Users

People who need to convert, edit, or inspect a file in their browser while keeping its contents on their device.

## Product Purpose

Loconvert helps people find a compatible tool, process their file locally, and preview or download the result. They can start with a file, browse by media family, or search by tool, format, or task.

## Capabilities and Constraints

The directory covers files, images, video and audio, PDFs, and 3D models. Codecs and model weights load as needed. Browser capabilities affect the available processing and previews. The interface supports English, Spanish, Italian, German, Portuguese, and French.

## Product Principles

- Put file selection and tool discovery at the start of the workflow.
- Explain local processing at file selection, where it informs the decision to open a file.
- Keep required controls visible and put contextual options within reach.
- Show a preview where practical and make the result easy to download or open in a compatible tool.

See the [design system](docs/design-system.md) for implementation details.
