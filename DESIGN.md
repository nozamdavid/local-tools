## Overview

Loconvert pairs a charcoal workspace with crisp rules, compact controls, and a single strong action color. Keep the workspace legible across dark, light, and system appearance settings. See the [design system](docs/design-system.md) for tokens, component APIs, and implementation details.

## Colors

Use charcoal surfaces in Dark and warm paper surfaces in Light. Signal lime marks primary actions with dark ink. Use semantic accent and tint tokens for focus, selection, and supporting emphasis. Media hues identify file families, and status colors communicate feedback.

## Typography

Use bold, fluid Geist display type for the home headline and smaller Geist headings for page and section titles. Keep body copy and controls in Geist. Use Geist Mono for counts, keyboard shortcuts, file metadata, and code.

## Layout

Pair the home headline with the file picker in the first section and stack them on narrow screens. Below it, use a compact directory with ruled rows for media families, category links, and counts. Let category links wrap within the row.

## Elevation & Depth

Separate rows and working surfaces with thin rules and changes in surface tone. Reserve shadow for layers such as dialogs.

## Shapes

Use modest corner radii on controls and panels. Keep directory rows flat and use a dashed boundary to identify file drop targets.
